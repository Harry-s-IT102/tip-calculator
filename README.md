# Tip Calculator

## Project Description
This is a simple, browser-based Tip Calculator built with HTML, CSS, and JavaScript. It allows a user to input a bill amount and a tip percentage, and then calculates both the total tip amount and the final bill total.

## How to Run the Project
1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enter a bill amount and tip percentage, then click "Calculate Total".
